# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/kombifyio/stackKits/security/advisories/new)
on this repository. Do not open a public issue for a security problem.

You will receive an acknowledgement, a severity assessment, and a fix or
mitigation timeline. Coordinated disclosure is preferred; credit is given in
the release notes unless you ask otherwise.

## Supported versions

Only the latest public release on
[github.com/kombifyio/stackKits/releases](https://github.com/kombifyio/stackKits/releases)
receives security fixes.

## Security baseline

The security model, release attestation and supported scope are described in
[docs/SECURITY.md](docs/SECURITY.md).
