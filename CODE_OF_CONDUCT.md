# Code of Conduct

This repository and the kombify community spaces on GitHub follow the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Scope

This code applies in every kombify repository, discussion, issue and pull
request, and wherever someone represents the kombify community.

## Reporting

Report behaviour that breaks this code to [info@kombify.io](mailto:info@kombify.io). A person reads
every report, decides it and tells the people involved the reason for the
decision. You can ask for the decision to be reviewed again.

## Enforcement

Possible measures, depending on severity: a reminder, hiding or removing a
contribution, a temporary limit on interacting, and a permanent block. Agents
may flag content for a decision; they do not decide.
