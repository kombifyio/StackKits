# Standalone troubleshooting

Generated by `stackkit docs emit-troubleshooting`. Do not edit this projection.

The [actionable-error authority](../internal/actionableerror/diagnostics.go) owns lifecycle diagnoses and consumes the existing [runtime taxonomy](../internal/applyoutcome/classes.go). CLI failures, `stackkit agent diagnose <error-id>` and the MCP `stackkit_self_check_plan` use those same contracts. A guidance lookup is not a health observation.

Keep the original workspace, Owner custody and saved choices when resuming. Use `stackkit -C <workspace>` from another directory. Inspect `stackkit logs latest --json` and use `stackkit support export --help` for bounded redacted evidence. Standard Mode is account-free; Advanced operations require Techstack dispatch.

Recorded failures in [CHANGELOG](../CHANGELOG.md):

- ACME duplicate-certificate limit: `acme_rate_limited`.
- Managed origin HTTP 526 / kombify.me certificate wait: `origin_tls_rejected`, `origin_certificate_missing`.
- Kopia OOM: `oom_killed`.
- PKI leaf before route: `pki_leaf_unavailable`.
- Unprivileged unshare probe: `namespace_probe_unverified`.
- Nominal RAM / MemTotal admission: `runtime-capacity-unsatisfied`.
- EC2 Nitro virtualization label: `host_virtualization_unrecognized`.
- Offsite backup child/router authorization: `authorization_time_mismatch`.
- Interrupted Cloud workspace rerun: `workspace_missing`, `binding_mismatch`.
- Interrupted restore after CLI upgrade: `restore_original_release_required`.
- Stored generation rejected by a newer CLI: `stored_plan_invalid`.
- Fresh Cloud/Modern standalone upgrade: `upgrade_kit_unsupported`.
- Interrupted whole-deployment removal: `remove_incomplete`.

A missing managed Origin CA certificate is a typed degraded completion; Standard/custom-domain issuance still fails on its actual TLS error.
